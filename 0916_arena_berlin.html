アレーナからベルリンへ

午前にアリアンツ・アレーナのツアー、夕方の便でベルリンへ。ホテル・アレーナ・空港の荷物の動線を中心にまとめました。

流れ
  • ホテルをチェックアウト（12:00まで）→ 荷物を預けて徒歩でアリアンツ・アレーナ
  • 10:15 アレーナツアー（約2〜2.5時間）→ 12:45 ホテルで荷物回収 → 空港へ
  • 18:00 ミュンヘン発 → 19:05 ベルリン BER 着 → FEX で市内へ
今日の出費
  • アレーナツアー €25（予約済み想定）· FC バイエルン博物館 +€12
  • 空港へ：ホテルの無料タクシー / MVV約€13
  • BER → 市内 ABC券 €5（D-Ticketなら不要）

タイムライン

  • 08:30朝食後に荷造り。ツアーが12:45頃まで続くので、出発前にチェックアウトして荷物をフロントに預ける（ノートの「ホテル12:00まで」はこのこと）
  • 09:35ホテル発。U6 Fröttmaning 駅からアレーナまではエスプラナーデを歩いて約25分。南正面（Haupteingang Süd）の回転ゲートを抜け「FC Bayern Museum / Arena Touren」の案内に従う
  • 10:00集合場所 Paulaner Fantreff Nord にツアー開始15分前までに到着（案内に明記）。予約確認のQRコードをスマホに用意
  • 10:15アレーナツアー。所要120〜150分。ピッチサイド、選手ベンチ、ロッカールーム、記者会見室。写真は自由
  • 12:30終了。FC バイエルン博物館（10–18時、€12、60〜90分）に寄る場合は空港到着が16:30を過ぎるので、寄るなら短めに。買い物は Megastore
  • 12:50ホテルへ戻り荷物を受け取る。ノートに「空港へ無料タクシー」「タクシー無料送迎あり」とあるので、前日までにフロントで13:30発を予約しておく。Fröttmaning から空港は高速A9で約20分
  • 14:00空港着。国内線なので出発の90分前で十分。ターミナルは航空会社で異なる（ルフトハンザなら T2）。Eチケットで確認
  • 18:00ミュンヘン発 → 19:05 BER 着。到着は T1。荷物受取後、地下の駅へ（表示「Bahnhof」）
  • 19:40FEX または RE でベルリン中央駅へ約23〜30分（4本/時）。切符は VBB の ABC 券 €5。D-Ticket は BER を含む ABC 全域で有効。S-Bahn（S9/S45）は45分かかるので急ぐなら FEX
  • 20:15ベルリン中央駅着。宿泊先へ。夕食は中央駅内（Rewe・各種テイクアウトが22時以降も営業）で済ませてもよい
荷物の動線が今日の肝。ホテル → アレーナ → ホテル → 空港の順になるので、チェックアウト時に「13:30にタクシーで空港へ、それまで荷物を預けたい」と伝えておく。ノートの無料タクシーが「空港→ホテル」の片道だけの場合は、Fröttmaning → 空港のタクシーは約€70〜90。

ホテル → アレーナ集合場所徒歩約25分U6 Fröttmaning 駅の東側からエスプラナーデ（広い歩道橋）をアレーナへ。南正面の回転ゲートを抜け「FC Bayern Museum / Arena Touren」の表示に従って北側へ回る。集合場所は Paulaner Fantreff Nord
アレーナ → ホテル徒歩25分来た道を戻る。荷物を受け取る
ホテル → 空港（本命）ホテルの無料タクシー約20分高速 A9 で北へ。前日にフロントで「13:30、Flughafen Terminal ○」と予約。ターミナルは航空券で確認（ルフトハンザ・ANA 系は T2）
ホテル → 空港（公共交通）U6 → S8約1時間15分Fröttmaning → U6 → Marienplatz（19分）→ 地下1階の S-Bahn へ上がる → S8「Flughafen München 行き」（東回り、38分）。S1 も空港行きだが西回りで遅い。空港駅は T1 と T2 の間の地下、T2 へは MAC（中央エリア）経由で徒歩5分
BER 到着 → 駅徒歩5〜8分T1 到着ホール（Level E0）で荷物を受け取り、案内「Bahn / Train」に従って地下2階の駅「Flughafen BER – Terminal 1-2」へ
BER → ベルリン中央駅FEX または RE23〜30分番線は駅の電光掲示板で確認（FEX/RE と S-Bahn は別ホーム）。FEX は Südkreuz → Potsdamer Platz → Hauptbahnhof のみ停車。S9 は45分かかるが Ostkreuz・Alexanderplatz 方面に泊まるなら乗り換えなしで便利
ベルリン中央駅 → 宿S-Bahn / U5—中央駅は地下（Gl. 1–8）と高架（Gl. 11–16）。FEX は地下に着く。S-Bahn（S3/S5/S7/S9）は高架 Gl. 15/16、U5 は地下。宿の最寄り駅が決まったら追記
切符 BER〜市内は VBB の ABC 券 €5（券売機・BVG アプリ）。券売機の紙券は乗る前に刻印。以後ベルリン市内は AB 券で足りる。D-Ticket なら空港含めて全部有効。
