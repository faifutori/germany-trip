アレーナからベルリンへ

午前にアリアンツ・アレーナのツアー、夕方の便でベルリンへ。ホテル（中央駅前）・アレーナ・空港の荷物の動線を中心にまとめました。

予約済み・決定済み

  • アリアンツ・アレーナ ツアー 10:15（済、残席あり）。集合は Paulaner Fantreff Nord、15分前
  • 飛行機（済）ミュンヘン 18:00 → ベルリン 19:05（7/20 チェック済み）。12:00 からオンラインチェックイン可
  • AWA Hotel チェックアウト 12:00 まで。ノート：空港へ無料タクシー送迎あり（要確認）
流れ
  • チェックアウトして荷物を預ける → U-Bahn で Fröttmaning → 徒歩でアレーナ
  • 10:15 アレーナツアー（約2〜2.5時間）→ 13:30 ホテルで荷物回収 → 空港へ
  • 18:00 ミュンヘン発 → 19:05 ベルリン BER 着 → FEX で市内へ
今日の出費
  • アレーナツアー €25（予約済み）· FC バイエルン博物館 +€12
  • U-Bahn 往復 + 空港 S-Bahn：MVV Airport-City-Day-Ticket 約€16 が便利（D-Ticket なら不要）
  • BER → 市内 ABC 券 €5

タイムライン

  • 08:30朝食後に荷造り。ツアーが12:45頃まで続くので、出発前にチェックアウトして荷物をフロントに預ける
  • 09:05ホテル発。中央駅の地下から U4/U5 で Odeonsplatz（2駅）→ U6「Garching-Forschungszentrum 行き」で Fröttmaning（約18分）。合計約30分
  • 09:35Fröttmaning 着。エスプラナーデ（広い歩道橋）を歩いてアレーナ南正面へ、回転ゲートを抜けて「FC Bayern Museum / Arena Touren」の案内で北側へ。約25分
  • 10:00集合場所 Paulaner Fantreff Nord。予約のQRコードを用意
  • 10:15アレーナツアー。120〜150分。ピッチサイド、ベンチ、ロッカールーム、記者会見室。写真自由
  • 12:30終了。FC バイエルン博物館（€12、60〜90分）に寄ると空港到着が16時を過ぎるので、寄るなら30分だけ。買い物は Megastore
  • 12:50Fröttmaning から U6 → Odeonsplatz → U4/U5 → 中央駅。ホテルで荷物を受け取る
  • 13:45ホテル → 空港。ノートの無料タクシーが使えるなら前日にフロントで 13:45 発を予約（約35分）。なければ中央駅地下から S8「Flughafen München 行き」で40分（S1 も可）
  • 14:30空港着。国内線は90分前で十分。ターミナルは航空会社で異なる（ルフトハンザなら T2）。Eチケットで確認
  • 18:00ミュンヘン発 → 19:05 BER 着。到着は T1。荷物受取後、案内「Bahn / Train」で地下2階の駅へ
  • 19:40FEX または RE でベルリン中央駅へ23〜30分（4本/時）。切符は VBB の ABC 券 €5（D-Ticket は BER を含む ABC 全域で有効）
  • 20:15ベルリン中央駅着。宿へ。夕食は中央駅内でも済ませられる（22時以降も営業）
荷物の動線が今日の肝。ホテル → アレーナ → ホテル → 空港の順なので、チェックアウト時に「13:45 に空港へ出発、それまで荷物を預けたい」と伝える。ノートの無料タクシーが「空港→ホテル」の片道だけなら、中央駅から S8 が最も確実（40分、10分ごと）。

区間乗り物所要詳細
